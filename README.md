# peerflow
Ce projet consiste en la création d’une application de partage de fichiers pair‑à‑pair (P2P) inspirée d’uTorrent, développée dans le cadre du cours de Systèmes Distribués. L’objectif est de mettre en œuvre les principes des architectures décentralisées et de comprendre les mécanismes qui assurent la fiabilité et la performance des réseaux P2P.
